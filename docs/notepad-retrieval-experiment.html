What changed

Exact still wins

The existing case-insensitive substring path runs first, preserving title, slug, tag, and body behavior.

Lexical fallback

Only after a literal miss, the same search ranks token coverage with title/slug above tags above body and IDF favoring distinctive terms.

Enough context now

Top results return complete bodies up to 2,000 characters. Connected notes are explicitly discovery context, not evidence.

Grep-style alternatives

| acts as an OR separator naturally: both boats | ships and boats|ships search the two terms. Notes matching both rank above notes matching one; no query parser or new mode was needed.

Boundary

This is deliberately lexical, not semantic. It fixes the measured failure with core code and no dependency. QMD remains the future enhancement for concepts that share no vocabulary; the product should still expose one search surface when that arrives.

Reproduce with npm run eval:notepad. The harness uses Node.js standard-library APIs and the configured Pi model.
